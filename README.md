# Darukaa.Earth — Geospatial Analytics Platform for Carbon & Biodiversity Projects

## 🌍 Overview

**Darukaa.Earth** is a full-stack geospatial data analytics platform designed to help organizations manage, visualize, and monitor **carbon and biodiversity projects** across multiple geographical sites.

The platform provides a centralized dashboard where administrators can:

* Create and manage environmental projects
* Add multiple geographical sites to projects
* Draw site boundaries directly on an interactive map
* Store geographical polygon data
* Calculate site area and centroid
* View carbon and biodiversity metrics
* Monitor environmental performance over time
* Visualize historical site performance using interactive charts
* Generate AI-assisted insights from project/site data
* Secure user data through authentication and user-level data ownership

The application combines **geospatial visualization, environmental analytics, database management, authentication, and AI-assisted analysis** into a single platform.

---

# 🎯 Problem Statement

Carbon and biodiversity projects often involve multiple locations, large geographical areas, and environmental measurements collected over time.

Managing this information using spreadsheets or disconnected tools creates several problems:

* Difficult project and site management
* No centralized geographical view
* Difficult visualization of site boundaries
* Manual calculation of geographical information
* Difficult tracking of carbon performance
* Difficult biodiversity monitoring
* Limited historical trend analysis
* Lack of centralized environmental insights

Darukaa.Earth addresses these challenges through an interactive web-based platform.

---

# 💡 Solution

Darukaa.Earth provides a centralized platform with four major capabilities:

### 1. Project Management

Administrators can create environmental projects and maintain project information.

### 2. Geospatial Site Management

Each project can contain multiple geographical sites.

Users can draw polygon boundaries directly on an interactive Mapbox map.

### 3. Environmental Analytics

Each site contains environmental metrics including:

* Carbon emissions/removal
* Biodiversity score
* Tree cover percentage
* Geographic area
* Geographic centroid

### 4. AI-Assisted Insights

The platform can analyze site information and generate an AI-powered environmental insight to help users understand project performance.

---

# ✨ Key Features

## 🔐 Authentication

The application provides authenticated access to the dashboard.

Users can:

* Register/login using email authentication
* Verify login using an email verification code
* Access their own projects and sites
* Sign out securely

User-specific data ownership prevents users from accessing another user's project data.
